GET STARTED / YOUR OWN MODEL

내 API로 연결하고 시작하세요.

Workmate는 개인이 사용하는 OpenAI 호환 LLM을 연결합니다. 준비할 것은 API 기본 주소, API 키, 모델 ID 세 가지입니다.

  1. 워크스페이스 오른쪽 위의 API 연결됨 · 모델 설정됨 · 규칙 기반 배지를 누릅니다.
  2. API 제공자를 선택하거나 직접 입력합니다. 기본 주소는 https://제공자주소/v1처럼 제공자가 안내한 경로까지 입력합니다.
  3. 발급받은 API 키와 정확한 모델 ID를 입력합니다. 비밀번호나 일반 서비스 로그인 정보를 입력하는 칸이 아닙니다.
  4. 연결 확인 후 적용을 누릅니다. 짧은 실제 요청에 성공한 경우에만 새 설정을 적용합니다.
  5. 설치형에서 다음 실행에도 사용할 경우 이 PC에 저장을 선택합니다. 키는 프로젝트의 .env에 저장되며, 화면이나 자료 묶음에 다시 표시하지 않습니다.
온라인에서는 방문 세션마다 자신의 API를 연결합니다. 키는 해당 세션의 서버 메모리에만 보관하며, 서버 재시작 시 다시 연결합니다. 브라우저 저장소와 GitHub에 키를 기록하지 않습니다. API 사용료는 연결한 제공자의 계정에 청구될 수 있습니다.

호환 조건은 /chat/completions, Bearer 인증, JSON 객체 응답(response_format: json_object)입니다. Azure 전용 또는 Anthropic 원본 API는 OpenAI 호환 게이트웨이를 이용하세요. 온라인 연결은 OpenAI·OpenRouter·DeepSeek·Groq·Mistral·Google의 공개 호환 주소로 제한하며 개인 서버 주소는 설치형에서 이용합니다.

연결이 되지 않을 때

401 키와 제공자 일치 여부 · 402 잔액·한도 · 404 주소와 모델 ID · 429 요청 제한을 확인하세요. JSON 응답 오류는 모델의 구조화 응답 지원과 추론 설정을 확인합니다. 설치형의 localhost 주소는 Workmate 서버가 실행되는 PC를 뜻합니다.

.env 파일로 직접 설정하기

프로젝트의 .env.example을 .env로 복사해 아래 세 값을 채운 뒤 서버를 다시 시작합니다. 환경 변수로 전달한 값이 파일보다 우선합니다.

WORKMATE_LLM_BASE_URL=https://your-provider.example/v1
WORKMATE_LLM_API_KEY=여기에_개인_API_키
WORKMATE_LLM_MODEL=제공자의_모델_ID

.env 파일은 공유하지 않습니다. 현재 연결 해제는 실행 중 연결만 해제하므로 저장한 설정을 없애려면 .env에서 해당 값을 지우고 서버를 다시 시작하세요.

AGENT STUDIO / STEP BY STEP

에이전트에게 맡기고, 결과를 업무로 연결하기

왼쪽 에이전트 스튜디오를 엽니다. 회의 후속 정리, 의사결정 브리프, 프로젝트 레이더, 주간 회고 중 하나를 선택하거나 내 방식에 맞는 프로필을 만드세요.

전문 분야이럴 때 사용하세요확인할 결과
회의 후속 정리회의 메모를 업무로 정리할 때결정, 담당자와 기한, 후속 업무
의사결정 브리프도입 방식·외주·일정 등 대안을 비교할 때장점과 비용, 기준, 남은 질문
프로젝트 레이더진행 중인 업무에서 빠진 일을 찾을 때기한 경과, 보완 대기, 담당 미지정
주간 회고업무·학습·개인 목표를 돌아볼 때최근 완료 기록, 다음 행동, 기억 후보

1. 먼저 한 번 실행해 보기

  1. 전문 에이전트를 선택하고 개별 요청을 엽니다.
  2. 바로 시작하기에서 예시를 선택하거나 회의 메모·선택지·개인 기록을 붙여 넣습니다.
  3. 에이전트 실행을 누릅니다. 실행 과정에서 자료 수집, 전문 분석, 근거 확인, 결과 전달 상태를 확인합니다.
  4. 결과 · 다음 행동에서 결정과 후속 업무를 읽고, 참고 근거에서 실행에 사용한 원문과 인용 확인 기록을 봅니다.
  5. 결과 받기를 누르면 요청·결과·원문을 담은 HTML 결과서를 내려받습니다.

2. 선택한 결과만 저장하기

  1. 다음 행동에서 필요한 항목을 체크하고 선택한 업무 등록을 누릅니다. 오늘의 업무에 미완료 업무로 추가됩니다.
  2. 다음에도 기억할 내용에서 확인한 항목을 체크한 뒤 선택한 기억 저장을 누릅니다.
  3. 같은 결과 항목을 다시 선택해도 중복 생성하지 않습니다. 같은 이름의 기억에 다른 내용이 이미 있으면 기존 내용을 유지하고 충돌을 알립니다. 내 업무 기억에서 직접 확인하세요.
기한과 담당자가 명시되지 않은 항목은 비워 둡니다. 날짜만 입력한 기한에는 임의 시각을 붙이지 않습니다. 원문에서 확인되지 않은 기한·담당자는 결과에서 제거하며, 인용이 확인되지 않은 기억 후보는 저장할 수 없습니다.

3. 내 방식의 프로필 만들기

  1. 에이전트 만들기를 눌러 이름, 전문 분야, 소개와 작업 지침을 입력합니다. 기존 카드의 설정을 수정하거나 선택한 에이전트 복제로 시작해도 됩니다.
  2. 프로젝트와 참고 자료를 정합니다. 문서는 최대 20개 선택하며, 프로젝트를 지정하면 같은 프로젝트 자료를 선택합니다.
  3. 선호와 원칙을 분석에 반영하려면 저장된 업무 기억 참고를 켜고 설정 저장을 누릅니다.
  4. 다음 실행부터 저장한 설정을 사용합니다. 이전 실행은 당시의 설정과 자료 사본을 유지합니다. 프로필을 보관해도 이전 결과는 남습니다.

프로젝트를 지정하고 문서를 따로 선택하지 않으면 해당 프로젝트의 자료를 사용합니다. 프로젝트와 문서를 모두 선택하지 않은 회의·의사결정 실행은 요청문을 기준으로 처리하며, 레이더·회고는 등록된 업무 전체를 집계합니다. 업무 기억은 사용을 켠 경우에만 분석에 포함합니다. 긴 자료나 많은 기록은 포함한 범위와 제한을 결과에 표시합니다.

작업 지침은 API 연결 시 모델 분석에 반영합니다. API가 없을 때에는 선택한 전문 분야와 자료 범위에 따라 명시 문장을 추출하고 업무 기록을 집계합니다. 임의의 웹사이트 접속·파일 조작·메일 발송 지침을 수행하는 범용 실행기는 아닙니다.

4. 여러 에이전트에게 같은 목표 맡기기

  1. 협업 미션을 선택하고 미션 이름과 공통 목표를 입력합니다.
  2. 함께 실행할 에이전트를 최대 4개 선택합니다. 예를 들어 회의 후속 정리·의사결정 브리프·프로젝트 레이더를 함께 선택합니다.
  3. 미션 맡기기를 누릅니다. 각 프로필은 같은 요청을 자신의 분야와 참고 범위로 독립 실행합니다.
  4. 미션의 에이전트 카드를 눌러 개별 결과·근거·실행 과정을 확인합니다. 후속 업무 등록과 기억 저장은 각 결과에서 선택합니다.

미션은 전문 분야별 실행과 결과를 묶어 보여 줍니다. 에이전트끼리 임의로 메시지를 보내거나 끝없이 작업을 추가하지 않습니다. 공개 서버의 실행 여유가 없으면 진행 중인 작업이 끝난 뒤 다시 실행하세요.

DESKTOP MINI / WINDOWS

브라우저를 닫아도, 곁에.

Windows용 Workmate Mini가 바탕화면과 트레이에 머뭅니다. 작은 모아를 누르거나 Ctrl + Alt + Space로 대화창을 열어 바로 요청하세요.

Windows 64-bit

바탕화면 모아

상단 점을 끌어 위치를 바꾸고, 항상 위 표시를 켜거나 끕니다. 대화창을 닫으면 트레이에 남고, 트레이 메뉴에서 완전히 종료합니다.

필요한 순간의 알림

확인할 업무는 작은 말풍선으로 표시합니다. 집중 시간과 알림 쉬기 설정을 함께 적용하며, 알림이 다른 창의 입력을 가로채지 않습니다.

로그인과 함께 시작

설정에서 Windows 로그인 시 시작을 켤 수 있습니다. 서버가 실행 중이면 연결하고, 꺼져 있으면 Mini가 로컬 서버를 함께 시작합니다.

설치형 Mini는 이 PC의 워크스페이스에 연결합니다. Windows가 꺼져 있거나 Mini와 서버가 모두 종료된 동안에는 작업이 실행되지 않습니다. 다른 PC에서는 Python과 업무앱 실행 의존성을 먼저 준비하세요.

1. 오늘 계획과 모아

  1. 홈에서 프로젝트와 가용 시간을 선택하고 오늘 계획 만들기를 누릅니다.
  2. 계획의 제목을 누르면 관련 업무를 확인할 수 있습니다. 재생 아이콘은 집중 타이머를 시작합니다.
  3. 오른쪽 아래 모아를 누르거나 Ctrl + Shift + Space로 빠른 대화를 엽니다.
  4. “오늘 먼저 확인할 일 2개 알려줘”, “알림은 간결하게 해줘라고 기억해”처럼 요청합니다.
  5. 웹에서는 상단 확장 아이콘으로 작은 별도 창을 엽니다. Windows Mini는 브라우저와 별도로 실행하며 Ctrl + Alt + Space로 호출합니다. 설정에서 비서 이름과 알림을 바꿉니다.
계획 블록의 완료와 실제 업무 완료는 각각 관리합니다. 집중 시간을 마쳐도 업무 결과를 자동으로 완료 처리하지 않습니다.

2. Excel 기준본과 수정본 비교

  1. Excel 검증에서 기준본과 수정본을 선택합니다. 아래의 두 파일을 직접 업로드해도 됩니다.
  2. Excel 검증 실행을 누르고 오류·주의·변경과 셀별 이전/현재 값을 확인합니다.
  3. 복구 가능한 수식을 검토한 뒤 검토한 수식 사본에 복구를 누릅니다.
  4. 복원 사본과 복원 로그, 다시 검사한 보고서를 받습니다. 원본 파일은 보존됩니다.

3. 개발 티켓의 UAT 결과서 만들기

  1. 업무앱 제작에서 앱을 만들고, 개발 · UAT에서 지원하는 입력 규칙 변경을 적용합니다.
  2. 개발 티켓 · 결과서에서 티켓을 선택하거나 새로 만듭니다. 연결 앱, 요구사항, 요청자와 메일, 개발 담당자, 인수 기준을 입력합니다.
  3. 실행 담당자를 확인하고 UAT 실행 · 결과서 만들기를 누릅니다.
  4. 항목별 실제 판정과 자동 캡처를 확인합니다. 실행 날짜·담당자·앱 버전이 포함된 결과서 열기를 누릅니다.
  5. 메일 파일 받기로 결과서가 첨부된 EML을 받습니다. 메일 앱에서 받는 사람·내용을 검토한 후 전달합니다.
  6. 현업의 검토 후 인수·조건부 인수·반려와 의견을 기록합니다.
실제 결과서 ↗산출물 묶음 ↓
화면 검증은 업무앱 사본과 격리된 API를 사용합니다. 회사 시스템의 실제 운영 거래나 현업의 승인으로 간주하지 않습니다.

4. 자료와 반복 업무 연결

메뉴시작하는 방법
자료실문서를 작성하거나 TXT·MD를 업로드하고 프로젝트를 지정합니다.
자료 분석자료 질의, 문서 전후 비교, 업무 보고를 선택합니다. 결과에서 원문 근거를 펼쳐 봅니다.
후속 업무분석 결과의 제안 중 필요한 항목만 선택해 등록합니다.
업무 자동화기준 파일·수정본·결과를 저장할 앱을 지정합니다. 검사 후 보완이 필요하면 파일이나 필수 값을 바꾸고 재개합니다.
전체 검색Ctrl + K로 업무·문서·업무앱·레코드·기억을 찾습니다.

실행과 보관

온라인에서는 워크스페이스를 바로 엽니다. 내 PC에 설치하려면 실행 패키지를 내려받아 압축을 모두 풀고 workmate 폴더의 setup.ps1을 실행한 뒤 start.cmd를 실행합니다. 설치형 주소는 http://127.0.0.1:8765/입니다. 자세한 절차는 GitHub README에 있습니다. 처음 사용할 때 위의 개인 API 연결 절차를 진행합니다. Windows에서는 Workmate_Mini_실행.cmd 또는 Workmate Mini.exe로 비서를 시작합니다. Python 의존성과 화면 빌드는 setup.ps1에서 준비합니다.

설치형은 브라우저를 닫아도 저장된 작업이 남습니다. 온라인 저장 기간은 위 안내를 확인하세요. 서버가 꺼진 동안에는 주기 자동화와 기한 알림이 실행되지 않습니다.
