Windows Mini

첨부자료 ZIP · Mini 설치 파일 포함

첨부자료 ZIP을 풀고, Workmate_Assets/install/Workmate_Mini_Windows_v1.0.zip도 모두 풉니다. Python 3.11 이상과 Node.js 22.12 이상을 준비한 후 workmate/setup.ps1을 실행합니다. 이후 Workmate_Mini_실행.cmd로 시작합니다. 설치 과정은 패키지 저장소에 연결하며, 개인 LLM·계정 연결은 사용자 매뉴얼을 따릅니다.
