YOUR PERSONAL WORKSPACE

내 일을 기억하는
가장 가까운 비서.

해야 할 일, 주고받는 메일, 오늘의 일정까지. Workmate는 업무의 맥락을 기억하고
개인 비서·전문 에이전트·업무 도구를 연결해 다음 행동으로 이어가는 공간입니다.

01오늘을 모아 보는 비서 데스크

메일 사본·오늘 일정·실제 마감 업무를 함께 봅니다. 원문을 확인하고 답장·회의 준비·집중 계획으로 이어갑니다.

02후속 연락과 내 글쓰기

내가 답할 일과 기다리는 답을 직접 관리합니다. 말투·언어·서명·상용구를 저장해 다음 답장 분석에 반영합니다.

03개인 루틴과 Windows Mini

요일·시간·자료 범위의 브리핑을 예약하고 모아 알림으로 확인합니다. 브라우저 밖 Mini에서도 빠른 대화를 이어갑니다.

04Gmail·Outlook·캘린더

Google Calendar를 월·기간별로 조회하고 필요한 자료를 선택합니다. Google·Microsoft 읽기 연결과 EML·ICS 파일 가져오기를 지원합니다.

05전문 에이전트와 협업 미션

프로필마다 지침·자료·기억을 지정합니다. 최대 4개 에이전트에 같은 목표를 맡기고 실행 과정과 근거를 확인합니다.

06Excel 검증과 티켓 UAT

수식·입력·규칙 변경을 비교하고 검토한 수식을 사본에 복원합니다. 개발 티켓은 화면 캡처·날짜·담당자·판정을 결과서로 남깁니다.

자료 연결 → 브리핑·연락·루틴 → 내 방식의 전문 분석 → 원문 확인 → 다음 행동

8개 전문 분야 + 8개 업무 도구

메일 정리·답장 초안회의 사전 준비약속·후속 연락일정 맞춤 집중 계획회의 후속 정리의사결정 브리프프로젝트 레이더주간 회고

시작하기 · 온라인·Windows 설치형. 개인 LLM API로 맥락 분석을 확장합니다. Google·Microsoft 연결에는 본인 앱 설정·로그인·승인이 필요하며 EML·ICS는 계정 없이 가져옵니다.
동작 범위 · 예약은 서버 실행 중, 원문은 가져온 사본 기준입니다. 답장 전송·캘린더 등록은 사용자가 수행합니다. Excel은 정적 검사, UAT는 지원 업무앱 검증입니다. 온라인 자료는 세션·서버 종료 시 초기화될 수 있으며 계정은 다시 연결합니다.
