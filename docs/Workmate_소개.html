실행 방식과 지원 범위

중앙 LLM의 분류·계획과 역할별 실행기를 결합한 구조입니다. 스튜디오는 자료 수집 → 전문 분석 → 근거 확인 → 결과 전달의 정해진 단계로 실행하며, 협업 미션은 선택한 프로필의 실행을 묶어 보여 줍니다. Excel은 결정적 검사 규칙, 자동화는 검사 → 보완 대기 → 등록 절차를 사용합니다. 앱 제작과 변경은 구조화된 계획과 검증된 CRUD 템플릿을 사용합니다. 모든 역할이 독립적인 범용 ReAct 루프를 수행하는 구조는 아닙니다.

설치형은 로컬 개인 워크스페이스이며 Windows Mini는 브라우저와 독립적으로 동작합니다. 온라인용 서버는 방문자별 데이터·파일·API 연결을 분리합니다. 집중 계획은 선택한 일정과 업무를 기준으로 충돌을 계산하며, 사용자가 캘린더에 가져올 ICS를 제공합니다. 가져오지 않은 일정까지 비어 있다고 판단하지 않습니다. UAT는 이 플랫폼에서 만든 업무앱과 지원 검증 기준을 대상으로 합니다. 외부 ERP의 운영 거래를 실행하지 않습니다. Gmail·Google Calendar·Microsoft 365는 사용자가 승인한 읽기 연결로 조회하고 선택한 내용을 자료로 가져옵니다. 자동 발송·일정 쓰기·지속 동기화는 수행하지 않습니다.
