Excel 검증 기능을 확인하는 두 파일

검사 기능을 확인하기 위한 업무 예제입니다. 수정본에는 검사를 위해 의도적으로 잘못된 수식과 값을 넣었습니다.

기준본 다운로드　수정본 다운로드

확인한 사례 59개실제 사본 복원 5셀

기준본도 일부 시트에 동일한 미지원 수식·중복 ID를 포함한 대조 실험입니다. 정상 업무용 양식이 아닙니다. 재계산 없는 정적 검사의 범위를 확인하는 예제입니다.

실행 순서

  1. Workmate의 Excel 검증에서 기준 원본에 기준본, 수정본에 수정본을 업로드합니다.
  2. 검증 실행 후 발견 사항, 변경 목록, 지원 범위를 확인합니다.
  3. 01_수식복원 시트의 제안을 검토하고 사본 복구를 실행합니다. 원본 두 파일은 바뀌지 않습니다.
  4. 복원 사본을 다시 검사합니다. 데이터 오류·모호한 ID·미지원 수식은 남는 것이 정상입니다.
  5. 일괄 검증은 동일 기준본에 수정본과 기준본을 각각 비교해 볼 수 있습니다. 최대 10개 수정본을 독립 비교하며 일괄 복원은 지원하지 않습니다.

실제 실행 결과: 오류 26건 · 검토 23건 · 변경 45건. Excel 재계산 미실행.. 복원 5셀. 원본 SHA-256 보존을 확인했습니다.

두 파일로 보장하지 않는 범위

  • 수식 재계산, 저장된 계산값의 최신성, 모든 순환 참조 및 업무상 정답은 보장하지 않습니다. 특히 06_수식검사범위!F9의 0 나누기는 정적 검사에서 확정하지 않습니다.
  • 드롭다운 정의의 변경은 비교하지만 모든 사용자 정의 유효성 수식을 계산하거나 규칙을 자동 복원하지 않습니다.
  • 용량·압축 해제 한도, 20만 셀 제한, 손상 ZIP, 매크로 거절, 일괄 일부 실패, 차트·피벗·외부 연결 등 보존 불가 파일의 복원 차단은 별도 API/단위 검증 범위입니다. 이 두 파일에 손상·대용량·외부 연결은 넣지 않았습니다.
  • 배열 수식·데이터 표·외부 파일 참조의 모든 형태는 이 예제에서 직접 확인하지 않습니다. #SPILL!·#CALC!의 rich-value 원형은 범위 밖이며, 07번 시트의 두 사례는 Excel에서 열리는 표준 #VALUE! 호환 오류로 저장했습니다. 이 문서의 확인 결과는 표에 명시한 사례에 한정됩니다.
  • 수식의 네이티브 재계산 검증은 수행하지 않았습니다. 제작 도구로 저장된 모든 시트를 다시 읽어 렌더링했으며, 실제 검사 엔진·사본 복원을 확인했습니다.
