[업무 예제] ERP 전환 준비 체크리스트
실행 단계와 담당 역할을 설명하는 가상 SI 자료입니다. 실제 운영 시스템 접속 명령이나 전환 승인 지시가 아닙니다.

[E-01] 전환 전 자료 동결
전환 대상 코드와 기준정보의 버전, 원천 파일과 추출 기준 시각을 기록한다. 수정 요청이 들어오면 원본과 수정본을 구분하고 변경 이유를 남긴다. 데이터가 없는 항목을 추정값으로 채우지 않는다.

[E-02] 대조 기준
건수, 금액 합계, 코드 유효성, 필수값과 중복 식별자를 점검한다. 정적 파일 검사로 확인한 항목과 실제 ERP 계산 또는 원장 대사로 확인할 항목을 나눈다. 수식 복원 사본을 만들었다고 전환 데이터 검증이 끝난 것은 아니다.

[E-03] 인터페이스 준비
수신처별 파일 규격, 인코딩, 필수 항목과 오류 재처리 키를 확인한다. 정상 입력뿐 아니라 중복, 누락, 지연과 한 건의 잘못된 입력을 포함한 묶음 처리를 시험한다. 실패한 입력은 근거와 함께 보완 대상으로 남긴다.

[E-04] 실행 승인과 복구
업무 담당, 개발 담당과 운영 담당이 각각 확인할 기준을 문서화한다. 전환 실행과 되돌리기는 별도 승인 대상이다. 현재 플랫폼은 운영 ERP에 연결되지 않으므로 실제 전환이나 복구를 수행했다고 표시하지 않는다.

[E-05] 인계 산출물
코드 매핑 표, 데이터 대조 결과, 예외 목록, 요구사항 변경 기록, UAT 증거와 운영 연락 역할을 묶어 전달한다. 담당 역할과 실제 연락처를 구분하고 전달 자료의 최신 버전을 표시한다. 미해결 항목은 담당자와 기한을 붙여 다음 작업으로 남긴다.
