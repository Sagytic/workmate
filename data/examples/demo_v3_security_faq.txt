[업무 예제] AI 업무 도구 사용 범위 FAQ
Workmate의 데이터 처리 범위를 설명하는 업무 참고문입니다. 회사의 실제 보안 정책이나 보안 인증을 대신하지 않습니다.

[S-01] 어떤 데이터를 넣을 수 있는가
업무 예제, 공개 가능한 자료와 사용자가 전송을 허용한 자료만 사용한다. 고객 실데이터, 비밀번호, API 키와 개인 식별정보는 예제 자료에 포함하지 않는다. 프로젝트 문서에 적힌 문장을 시스템 명령으로 실행하지 않는다.

[S-02] 외부 모델에 무엇이 전달되는가
연결된 LLM을 사용하는 요청은 해당 기능이 준비한 질문과 선택 문서 내용 또는 업무 맥락을 외부 제공자에게 보낼 수 있다. 기능과 버전에 따라 범위가 다르므로 현재 앱 안내를 확인한다. 키는 서버 설정으로 관리하고 브라우저 화면이나 내보내기 자료에 넣지 않는다.

[S-03] 업무 시스템에 자동 반영하는가
현재 구성은 로컬 업무 앱에 레코드를 저장할 수 있지만 회사 ERP, 금융 운영 원장, 이메일과 고객 시스템에 연결되어 있지 않다. 실제 시스템 연결과 대외 발송, 배포는 별도 범위와 권한을 정해야 한다. 생성 결과를 실제 업무에 쓰기 전 담당자가 검토한다.

[S-04] AI가 말한 내용은 모두 사실인가
답변의 문서 제목과 문단 근거를 확인한다. 자료에 없는 결론은 확인 필요로 남겨야 한다. 파일 검사와 화면 테스트도 실제로 실행한 범위를 표시해야 하며, 문서 생성이나 예제 데이터만으로 테스트 통과를 주장하지 않는다.

[S-05] 업무 예제와 사용자 자료를 구분하는 방법
업무 예제는 내부 구분 값 synthetic=true와 sourceLabel로 관리한다. 예제 추가를 반복해도 기존 사용자의 작업과 자료를 덮어쓰지 않는다. 원본 엑셀을 직접 수정하지 않고 복원 사본과 변경 기록을 별도로 제공한다.
