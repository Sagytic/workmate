# Workmate 업무 예제

SI 업무를 바탕으로 프로젝트, 작업, 지식 자료와 업무 앱을 살펴볼 수 있는 예제 모음입니다.

화면의 **예제 준비** 또는 `POST /api/demo/seed`를 처음 실행하면 프로젝트 5개, 수동 업무 40개, 지식 문서 10개, 기억 5개, 알림 6개, 업무 앱 4개, 레코드 48개, 꺼진 자동화 3개와 실행 예제 16개를 준비합니다. 항목 ID는 `demo_v3_`로 시작합니다. 같은 초기화를 반복해도 기존 항목이나 사용자의 수정을 덮어쓰지 않습니다. 

수동 업무는 시작 전, 진행 중, 입력 대기, 완료 상태로 구성됩니다. 완료 업무에는 완료 시각과 상태 기록이 있습니다. 사용자의 기존 작업 상태와 결과는 변경하지 않습니다. 자동화는 기본적으로 꺼져 있고 반복 스케줄은 등록하지 않습니다.

고객 요청, 정산 차이, 견적·증빙, 프로젝트 이슈 앱은 허용된 스키마로 실제 `create_app` 함수를 실행하여 생성합니다. 앱마다 12개 레코드가 있으며 소스는 `data/artifacts/demo_v3_apps/` 아래에 저장됩니다. 앱 생성과 UAT 실행은 구분되며 검수 결과는 테스트 실행 후 확인합니다.

문서는 빈 줄로 나눈 문단과 문단 번호를 포함합니다. 요구사항 v1·v2, 정산 가이드 v1·v2, 고객 협의, 견적 검토, 장애 회고, 보안 FAQ, 인수 기준과 주간 메모가 지식 자료에 등록됩니다. `demo_v3_erp_cutover.txt`는 추가 다운로드용 자료입니다.

`demo_v3_catalog.json`에는 Excel 3개, 지식 질문 3개, 변경 영향 분석 2개, 보고 2개, 앱 제작·개발 UAT·자동화·개인 업무 각 1개가 있습니다. `uses_llm`은 해당 실행 경로의 모델 사용 가능 여부입니다. 실행 결과는 생성된 작업에서 확인합니다.

권장 실행 순서는 수식 오류 검수 → 요구사항 영향 비교 → 근거 있는 주간 보고 → 고객 요청 앱 열기 → 완료 메모 규칙 변경·UAT입니다. 정상 Excel 검수 후 접수 예제는 버튼으로 1회 실행하며 기존 반복 자동화를 켜지 않습니다.
